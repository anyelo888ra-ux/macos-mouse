# 🍏🖱️ macos-mouse

Bring the fluid dynamic scrolling and cursor behavior of macOS to Windows and Linux. 

## ✨ Features
* **Dynamic Context Scroll:** Normal scroll when hovering over scrollable web pages, lists, or documents.
* **Cursor Zoom Control:** Smoothly resize your mouse pointer dynamically when scrolling over blank or static areas.
* **Lightweight & Open-Source:** Built purely in Python with low resource consumption.

## 🚀 Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt

   ```

 2. Run the background service:
   ```bash
   python main.py

   ```
